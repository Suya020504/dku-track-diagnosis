# 단국대학교 식품자원경제학과 트랙제 자가진단

학생이 트랙제를 이해하고 현재 이수 상태를 진단한 뒤 다음 수강 계획을 살필 수 있도록 만든 자가진단 보조 웹앱입니다. 단국대학교와 학과의 공식 공개 교육과정·안내는 규칙 검증의 출발점이며, 현재 화면과 테스트의 계산 입력은 제공된 최종계획을 구조화한 값입니다. 개인별 적용 학번·필수 변형·인정학점과 트랙 이수·졸업 여부는 반드시 학과의 공식 검토가 필요합니다.

## 운영 URL

[https://dku-track-diagnosis.vercel.app](https://dku-track-diagnosis.vercel.app)

2026-09-08 후속 버전은 홈·가이드·진단·결과·추천·플래너·자료·문의 화면을 목적별로 다시 구성했습니다. 직접 과목 선택을 중심으로 `이수 유형 → 이수 과목 → 진단 결과`만 필수 단계로 표시합니다. 관심 설문, 트랙 가이드와 학기 플래너는 선택 기능입니다. 공식 자료실에는 학과 현재 교육과정 47과목과 2026년 2학기 천안 실제 시간표 37분반을 추가했습니다.

현재 작업 소스는 `codex/track-service-expansion` 브랜치입니다. 기능 변경 `ed7a6b9`를 Vercel 배포 `dpl_Hip4cXPrZ4J19Maty7WLBq7vcVc2`로 운영 주소에 반영했습니다. 최신 결과는 [서비스 마감 검수](reports/validation/2026-09-08-service-completion-qa.md), 자료의 출처·조회 조건·적용 범위는 [공식 교육과정·시간표 반영 기록](docs/research/2026-09-08-official-curriculum-timetable.md)에 정리했습니다. 전체741개 테스트와 운영31화면×9크기279건을 검증했습니다. 반응형은 Chromium 뷰포트 검증이며 실물 기기 검증을 뜻하지 않습니다. PDF 자동 입력 beta와 개인별 학사 인정은 별도 확인 대상입니다.

## 사이트 목적

### 2026-09-08 서비스 완성 반영

- 과목 입력에서 완료·수강 중·계획을 직접 바꾸고, 검색·학년 필터로 목록을 좁힐 수 있습니다. 휴대폰은6개, 그 외 화면은12개씩 표시합니다.
- 세미나·인턴십 등 목록 밖에서 완료한 전공학점은 별도 입력합니다. 전체 전공학점에만 더하며 트랙 모듈에는 자동 반영하지 않습니다.
- 추천 후보를 수강 계획에 실제로 추가·해제하고 계획 시작 학기 기준의 상대 학기를 선택할 수 있습니다.
- 학기 계획 없이도 현재 진단을 보관할 수 있습니다. `?view=records`에서 최근12개의 진단·계획을 읽기 전용으로 열며 현재 입력을 덮어쓰지 않습니다.
- 가이드의 `?view=track-guide&section=application`에서 신청 전 학과에 확인할 내용을 안내합니다. 제공 자료의 표기 차이는 숨기지 않고 확인 항목으로 남깁니다.

새 제공 자료의 범위와 계산 반영 내용은 [PDF 대조 기록](docs/service-completion/2026-09-08-provided-pdf-audit.md)을 참고하세요. 로그인·기기 간 동기화는 추가하지 않습니다. 사용자가 제공한 PDF 원문은 비공개이며 저장소와 배포 파일에서 제외합니다. 출처 설명과 참고 쪽수, 별도의 학과 공개 자료 링크는 유지합니다.

안내 자료만으로는 트랙별 모듈, 이수 과목, 부족 과목을 한눈에 파악하기 어렵다는 문제에서 시작했습니다. 교육과정표를 그대로 옮기는 대신 학생이 “지금 무엇을 채웠고, 무엇이 남았는지”를 이해한 뒤 수강신청 행동으로 이어가게 하는 것이 목표입니다.

- 내가 선택한 트랙에서 어떤 모듈이 부족한지 확인
- 이미 들은 과목과 앞으로 들어야 할 과목 구분
- 복수 트랙 선택 시 트랙별 충족/부족 상태 비교
- 학년/학기 기준으로 남은 과목 후보 확인
- 현재 이수 과목 기준으로 가까운 트랙과 함께 고려할 추가 트랙 탐색
- 추천 과목을 다음·다다음 학기 계획으로 나눠 저장
- 관심, 현재 완료 과목, 졸업 전 계획 가능성을 서로 섞지 않고 세 축으로 비교
- 정규학기 계획, 수강량 조정, 추가 학기 가능성, 공식 확인 필요 상태를 구분

이 도구는 자가진단 보조용으로 제작했습니다. 트랙 이수와 졸업 여부는 학과 공식 안내 및 개별 심사로 확인해야 합니다.

## 현재 사용자 흐름과 시각 체계

전체 화면은 `깔끔한 전공 탐색 홈 × 학업 플래너` 체계로 구성합니다. 첫 화면에서는 관심 트랙 찾기와 현재 이수 현황 진단을 분리해 보여 주고, 진단 이후에만 부족 영역·다음 과목·선택형 학기 플래너로 이어집니다. 데스크톱과 태블릿은 같은 상단 주요 서비스 내비게이션을 사용하며, 모바일은 홈·진단·결과·계획 하단 내비게이션으로 핵심 흐름을 유지합니다.

홈은 크림색 책상, 가이드는 민트색 읽기 화면, 진단은 하늘색 입력 화면, 결과는 네이비 요약, 추천은 청록색 비교 화면, 플래너는 밀색 노트, 자료는 아이스블루로 구분합니다. 주요 실행 버튼과 완료·주의 상태의 의미는 페이지가 바뀌어도 같습니다. 작은 화면에서는 중복 단계 표시를 줄이고 과목 체크와 다섯 설문 응답을 먼저 보여줍니다.

주요 흐름은 다음 두 가지입니다.

- 내 관심 트랙 찾기 → 10문항 → 트랙 직접 선택 → 소속·이수 경로 → 이수 과목 → 결과 → 독립 추천 → 학기 계획
- 이수 과목 바로 진단 → 소속·이수 경로 → 이수 과목 → 목표 없이 5개 트랙 진행도 비교 또는 선택한 트랙 상세 결과

2·3학년도 중간 진입할 수 있습니다. 현재 완료 과목만 입력해 자가진단을 마칠 수 있고, 목표 트랙 선택과 학기 플래너는 결과를 본 뒤 필요할 때 이어갑니다.

학생의 소속·이수 경로를 먼저 분리하고, 진단 결과가 어떤 규칙 상태에 근거하는지와 필수·트랙·전체학점 진행도를 나누어 보여 줍니다. 관심 설문, 현재 완료 과목, 졸업 전 계획 가능성은 하나의 종합점수로 합치지 않으며, 진단·추천·계획 상태는 브라우저 저장소(v2)와 주소에서 복원됩니다. 이수 과목의 직접 선택이 완전한 기본 입력입니다. PDF 과목 불러오기는 브라우저 메모리 안에서만 검수하는 beta이며, 합성 fixture에서 자동 일치 0개·직접 확인 1개가 남아 release-ready가 아닙니다.

- 실제 이수 기준과 계획 포함 기준의 추천 결과 비교
- 학기별 참고 계획과 공식 확인 질문, 뒤로가기·앞으로가기·새로고침 복원
- 결과 저장/인쇄는 화면 출력 기능이며, PDF 과목 불러오기 beta는 과목 입력을 돕는 별도 기능입니다.
- Vercel 배포용 `vercel.json` 포함

이 앱은 미래 과목의 반복 개설이나 개인의 공식 졸업·트랙 이수를 보장하지 않습니다. 실제 개설·폐강·인정과 최종 졸업 판정은 해당 학기 수강신청 시스템과 학교·학과의 공식 검토를 따라야 합니다.

## 저장·개인정보·공식 자료 경계

- 진단·추천·계획은 계정 없이 현재 브라우저의 localStorage에 저장합니다.
- PDF beta는 브라우저 안에서만 읽고 검수 초안은 메모리에만 둡니다. 원본 파일, 원래 파일명, 읽은 원문을 저장하거나 서버로 보내지 않습니다.
- 현재 계산은 제공된 2026 최종계획을 구조화한 참고 계산입니다. 공식 공개 교육과정·시간표·학과 답변이 우선합니다.
- 2026 개설값은 과거 이력 스냅샷이며 미래 반복 개설을 보장하지 않습니다.
- 생성 개념 이미지는 공식 단국대학교 이미지가 아닙니다. 공식 캠퍼스 사진은 외부 재사용 허가 확인 전까지 앱 화면에 노출하거나 삽입하지 않습니다.

## 최근 업데이트 기록

### 2026-08-25 실제 서비스형 UX/UI 개편

토스의 `One thing per one page`, TDS의 색상·탭·목록 위계, 당근의 발견 가능성과 실험 중심 사례를 참고해 사용자가 다음 행동을 놓치지 않는 구조로 개편했습니다.

- 랜딩의 반복 섹션과 예시를 줄이고 트랙제 이해, 장점, 3단계 이용 흐름만 남겼습니다.
- 과목 선택은 큰 시간표 대신 읽기 쉬운 행 목록을 기본으로 하고 모듈별 보기와 검색을 추가했습니다.
- 결과에 개인 이수 이력 기준의 맞춤 트랙 추천과 추가 트랙 후보, 공통 도움 과목을 추가했습니다.
- 학기 계획에서 추천 과목을 다음 학기·다다음 학기·나중으로 배치할 수 있게 했습니다.
- 계획 과목은 실제 이수와 분리 저장하며 `계획 포함` 비교에서만 반영합니다.
- 반복 그라데이션과 동일한 카드 격자를 줄이고 네이비·포레스트 그린·쿨그레이의 명암 체계를 적용했습니다.
