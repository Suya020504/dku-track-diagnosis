## 가져올 것

- 왼쪽 안내책자 INDEX
- 관심 질문 → 트랙 탐색 → 학기 계획이 한 리본으로 이어지는 구조
- 입력 후 학기 플래너가 펼쳐지는 장면
- 오른쪽 상단의 제한된 컴퍼스 풍경
- 하늘·민트 종이 면, 단국 블루·학과 녹색, 밀색 연결 과목
- 저장·비교·점검이 플래너 가장자리 행동으로 붙는 구조

## 그대로 가져오지 않을 것

- 생성 이미지의 seal·로고·사용자명
- 시안 속 과목명·학점·학기·추천 수치
- 이미지 안에 그려진 버튼·검색·표
- 처음부터 모든 학기가 채워진 상태
- 작은 생성 한글 문구와 임의 아이콘

실제 구현은 현재 공식 seal 자산, semantic HTML, 정확한 과목·트랙 데이터, 접근 가능한 입력과 주소 상태로 다시 만든다.
