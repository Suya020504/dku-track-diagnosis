# 다중 트랙 여정 시안 구현 계약

사용자 승인: 여러 트랙 함께 선택·비교·계획, 신청 안내만 연결, 검증 후 GitHub와 운영 갱신. 기존 기록과 비공개 원문은 보존한다.

## 시각 기준

- 1536×1024 시안: 01-entry.png / 02-results.png / 03-plan.png. 생성 도구로 제작하고 로컬 이미지를 직접 확인했다.
- 공통: 실제 DKU 로고 파일 유지. 제목 34~38px/본문16px/제어15px, navy #17354b, primary #087b5d, white #fff, ice #eef5fa, mint #e8f4ed. planner만 ivory #faf7ef. 버튼 최소44px, radius8~12, 선1px, 간격8/16/24/32.
- 진입: 하늘색 짧은 타이틀 밴드 + 노트 이미지, 수평 단계선, 3개 가로 선택 행, 하나의 주 실행 버튼. 기존 과도한 아래 홍보 섹션은 제거하고 트랙 설명 링크는 유지.
- 결과: 선택 트랙 chips → navy 합산 잔여 밴드 → 남은 과목 표/트랙별 모듈 진도 2열 → 추가 트랙 발견 밴드 → 전공 전체 조건 접기 → 신청 안내·보관.
- 계획: 아이보리, 조건 입력 밴드, 과목행×학기열 표, 선택 트랙·미배치 rail, 보관 버튼. 모바일 표는 내부 가로 이동/머리·첫열 고정.
- 아이콘: 기존 TrackGlyph 및 Lucide outline, 18~24px. 로고를 생성 이미지로 대체하지 않는다.

## 정확한 주요 문구

‘내 수업으로 트랙을 완성해요’, ‘어디서부터 시작할까요?’, ‘트랙을 정했어요’, ‘관심으로 찾아볼래요’, ‘들은 과목으로 찾아볼래요’, ‘선택한 방법으로 시작하기’, ‘선택한 트랙, 남은 수업을 확인하세요’, ‘앞으로 들을 과목’, ‘함께 확인해 볼 트랙이 있어요’, ‘남은 수업을 학기별로 나눠보세요’.

## 필요한 의도적 차이

- 이미지의 학과명/과목/트랙 오기와 샘플 숫자는 실제 카탈로그·계산 결과로 교체한다. ‘식품경제’ 예시는 실제 5개 트랙의 ‘경제학’만 사용한다.
- 시안의 샘플학점·가짜 체크박스는 실제 상태와 동작으로 구현한다. 현재 이수 완료를 임의로 체크시키지 않는다.
- 학위/졸업과 구분하기 위해 ‘트랙 모듈’ 범위를 결과에 짧게 명시한다. 긴 검증 로그는 표시하지 않는다.
- 현재 학기는 수강 중 과목, 새 자동 추천은 다음 학기부터라 planner의 ‘시작 학기’를 ‘현재 학기’로 명료화한다.
- 기존 학과 YouTube·도움말·저장 오류 접근 경로는 기능상 유지한다. 실제 헤더는 기존 6개 메뉴를 유지해 진단 결과에 바로 접근할 수 있게 한다. 시안의 5개 메뉴와 다른 의도적 호환 결정이다.
- 노트 이미지는 별도 생성 자산으로 분리한다. 실사이트 텍스트·표·선택·이동은 HTML/React로 구현한다. 이미지 한 장을 UI로 사용하지 않는다.
- 목차 ‘내 정보→트랙 선택→이수 현황→학기 계획’은 결과·계획 상태를 표시하며, 가이드/설문/계획은 필요할 때만 이용한다.

## 검증

대표3분기, 2개·5개 트랙의 중복 없는 남은 과목, 미정 전공·구형 기록, 수강중 미리보기, 결과→계획, 이동·초안·보관 복원, 모바일390/430·태블릿·1920px 검수. 시안과 렌더의 카피/배치/타이포/색/표 및 이미지/반응형을 비교한다. 실제값 차이와 위 필수 차이는 분리해 기록한다.

## 구현 대조 기록 · 2026-09-09

1536×1024로 생성 시안과 실제 CUA 캡처를 각각 열어 대조했다. 캡처는 작업 폴더 `_workspace/journey-home-native.jpg`, `journey-result-native.jpg`, `journey-plan-native.jpg`에 보관한다. 픽셀 동일성 평가가 아니라 아래 계약의 구현 여부를 확인한 기록이다.
