# 페이지별 재구성 및 공식 시간표 통합

사용자 요청: 기존 페이지를 재활용한 색상 변경을 끝내고, 각 목적에 맞는 페이지를 하나씩 새로 제작한다. 공식 교육과정과 실제 시간표도 가져온다. 기존 페이지별 A안 색과 DKU 브랜드는 유지한다.

## 제품 판단 계약

| 항목 | 결정 |
| --- | --- |
| 현재 행동 | 학생이 트랙을 이해하고, 이수 과목을 넣고, 결과를 확인하고 필요하면 계획한다. |
| 병목 | 반복 출처와 큰 설명 제목이 행동을 밀어내며 '다음 모듈'이 자료실로 넘어가 목적과 화면이 어긋났다. |
| AI 필요 여부 | 화면·조회·계산에는 새 AI가 필요하지 않다. 시각 콘셉트만 이미지 생성 사용. |
| 규칙/UI | 공식 데이터와 기존 계산·저장 엔진을 사용하며 페이지 구성을 새로 작성한다. |
| MVP 포함 | 선택적 가이드, 소속별 질문, 직접 과목 선택, 현황·다음 과목·확인 결과, 비교, 선택적 플래너, 공식 교육과정/시간표/연락처. |
| MVP 제외+사유 | 계정·협업·학교 학적 연동: 이번 학생 흐름과 공식 공개 데이터 수집에 필요하지 않다. 실제 졸업 인증: 학교 권한이 필요하므로 제공하지 않는다. |
| 기존 결함+처리 | 출처는 자료 전용 탭, 필수 진단은 유형→과목→결과로 한정, 페이지별 기존 JSX 레이아웃을 목적에 맞게 대체. |
| 완료 판정 | 각 화면을 실제 브라우저에서 확인, 기존 기능·저장·주소 보존, 공식 원문 대조, 전체 테스트·타입·빌드 및 배포 검수. |

## 공통 계약

- 학생용 단국대학교 식품자원경제학과 트랙제 서비스. 지도·나침반·거리·위치 비유를 사용하지 않는다.
- 공식 DKU 로고 public/dku-logo.png와 학과 홈페이지·YouTube 링크를 유지한다.
- 홈 크림, 가이드 민트, 진단 하늘, 결과 네이비, 추천 청록, 플래너 밀색, 자료 아이스블루.
- 한 페이지 한 h1/main, 짧은 제목→핵심 행동/데이터→선택 상세. h1 30~42px PC/26~32px mobile, h2 20~26px, 본문 15~16px, 읽기 폭 제한.
- 큰 안내 패널·상태 패널을 화면마다 반복하지 않는다. 설명/신뢰 경계는 필요한 위치에서 간결하게, 전문 원문은 공식 자료 탭에서 제공한다.
- 필수 진단은 이수 유형→이수 과목→진단 결과. 모듈 자료·관심 추천·학기 플래너는 필수 단계가 아니다.
- 직접 과목 선택이 기본, PDF 선택 입력 유지. 완료·수강중·계획 의미와 개수 일치, 0개 검토 가능, 필수 적용·학점 계산을 바꾸지 않는다.
- 주전공/복수전공/부전공 등 타입, 저장 schema v2, URL/back/refresh, 오류·빈 상태·키보드 복귀를 보존한다.
- 새 의존성, 로그인, 학생 개인정보 입력, 파괴적 삭제를 수행하지 않는다. GitHub push/기존 Vercel 배포는 앞서 승인된 범위다.
- 작업자는 자신에게 배정된 파일만 편집하고 다른 작업자의 변경을 되돌리지 않는다. 하위 에이전트를 만들지 않는다.
- 기존 계산·검증 함수와 작은 입력/아이콘 부품을 재사용할 수 있지만, 페이지 수준의 JSX·배치·위계는 각 목적에 맞게 새로 구성한다.
- 실제 데이터·공식 트랙명이 이미지 시안의 예시 텍스트보다 우선한다. 생성 이미지는 학사 정보의 근거가 아니다.
- 344/360/390/430 모바일, 768/820/1024 태블릿·Fold, 1920×1080 PC에서 확인한다.

## 페이지 책임

1. 가이드: 일러스트와 3단계 개념 설명, 장점의 근거, 학위/트랙 기록 구분, 5개 트랙 비교, 공식 영상·자료를 각각 다른 구성으로 만든다. 공식 출처 목록은 videos에서만.
2. 진단: 프로필은 한 번에 한 선택, 과목은 간결한 검색/필터→접이식 행 체크→실제 선택 요약. 다음 결과 버튼이 가장 강하다.
3. 결과: 현재의 필수/트랙/전체 전공 현황을 먼저 요약하고 부족 조건은 펼쳐서 확인. 다음 과목은 이유가 있는 후보 목록. 공식 점검은 확인 목록. 세 페이지를 같은 긴 표로 만들지 않는다.
4. 추천: 설문은 질문/응답, 결과 비교는 다섯 트랙 및 근거를 비교하는 별도 구성. 관심/진행/계획 점수를 합치지 않는다. 재방문 답변과 추천의 사용자 선택권을 유지.
5. 플래너: 조건은 간결한 학기/수강량 폼, 일정은 학기별 배치, 확인은 미배치·공식 문의 목록. 개설 이력을 향후 보장으로 표현하지 않는다.
6. 자료: 트랙 자료, 모듈 탐색, 교육과정/실제 시간표, 공식 링크를 새 화면 구조로 분리. 모듈 조회를 진단 다음 단계로 표시하지 않는다. 공개된 실제 강좌만 시간표에 싣는다.
7. 홈/공통: 기존 자연스러운 캐치프레이즈 유지, 처음/재방문에 맞는 진단 CTA, 가이드·추천은 낮은 위계, 학기 계획은 선택 서비스. 페이지 전체를 다시 구성하되 로그인·가짜 수치가 없어야 한다.

## 공식 데이터

2026 교육과정과 2026-2 공개 시간표를 원문별로 대조한다. 권장 학년·학기와 실제 수업 요일·교시·분반은 다른 필드다. 공식 시각표 없이는 교시를 시각으로 추정하지 않는다. 트랙 목록 밖의 개설 과목을 자동으로 트랙 필수/학점에 넣지 않는다. 오래된 2026-1 이력과 새 2026-2 확인을 섞어서 모두 재확인했다고 표시하지 않는다.
