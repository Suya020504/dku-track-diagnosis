# PDF 가져오기 베타 fixture 명세

PDF 가져오기 베타는 실제 학생 문서를 저장소나 자동 테스트에 사용하지 않는다. 아래 fixture는 모두 테스트 전용 합성 데이터이며 이름, 학번, 연락처, 실제 성적을 포함하지 않는다.

## 생성·검증 기준

- 생성 런타임: 번들 Python, `reportlab 4.4.9`, `pypdf 6.10.0`.
- 한국어 글꼴: `C:\Windows\Fonts\malgun.ttf`. 글꼴이 없으면 읽을 수 없는 대체 문자를 만들지 않고 생성이 실패해야 한다.
- 정상 텍스트 fixture에는 `경제원론`, `통계학기초`, `마케팅조사분석`, `C-1`, `553110`, 오탈자형 문자열 `경제원롱`이 들어 있다.
- 이미지 전용 fixture는 정상 텍스트 fixture의 첫 페이지를 래스터화해 새 PDF에 이미지로만 배치했다.
- 암호 fixture는 정상 텍스트 fixture의 암호화 사본이며 앱은 암호를 묻지 않고 거부해야 한다.
- 손상 fixture는 `%PDF-`로 시작하지만 정상 페이지 트리와 교차 참조를 갖지 않는다.
- 동일 입력으로 두 번 생성해 다섯 파일의 SHA-256이 재현됨을 확인했다.

## 렌더링 확인

`pdftoppm 26.05.0`으로 네 종류의 유효 PDF를 모두 PNG로 렌더링했다. 총 56페이지가 만들어졌고, 본문 2쪽·이미지 전용 1쪽·암호 사본·51쪽 fixture의 1/26/51쪽을 확인했다. 한글 글리프, 표 열, 페이지 번호, 합성 자료 경고에서 겹침이나 잘림은 없었다. PNG는 `tmp/pdfs/`에서만 검수하고 저장소에는 남기지 않는다.
