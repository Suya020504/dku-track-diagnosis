# 학과 공식 교육과정·시간표 반영 기록

2026년 9월 8일, 로그인 없이 공개된 학교·학과 자료를 확인해 반영했습니다. 이 문서의 조회일은 새로 확보한 자료에만 적용합니다. 기존 2026-1 개설 이력을 이번에 다시 확인했다는 뜻은 아닙니다.

## 어떤 자료를 가져왔나요?

| 자료 | 확인한 범위 | 앱에서 사용하는 곳 |
| --- | --- | --- |
| 학과 현재 교과과정 | 학문기초·전공 47과목의 원문명, 학사 과목코드, 학점, 배치 학년·학기 | 자료실 → 교육과정 |
| 2026학년도 트랙 구성 | 5개 트랙, 15개 모듈과 연결 과목 | 트랙 가이드, 자료실 → 트랙·모듈 |
| 2026년 2학기 천안 시간표 | 27과목 37분반의 교수, 교시, 강의실, 수업방식, 변경·수강제한 주석 | 자료실 → 시간표 |
| 학교 교시표 | 주간 1~18교시와 야간 19~24교시 | 교시를 실제 시각으로 함께 표시 |

학과 교육과정 47과목, 트랙 구성 49과목, 직접 진단에서 선택하는 전공 45과목은 서로 범위가 다릅니다. 새로 확인한 학과 과목 10개를 임의로 트랙 모듈에 넣거나 진단 학점으로 자동 인정하지 않았습니다.

실제 시간표 37분반은 트랙에 연결된 25과목 35분반과, 트랙 구성 밖의 2과목 2분반입니다. 같은 과목에 여러 분반이 있으므로 과목 수와 분반 수를 나누어 표시합니다.

## 원문과 검증 방법

- [학과 정규 교육과정](https://cms.dankook.ac.kr/ko/web/ere/%EC%A0%95%EA%B7%9C-%EA%B5%90%EC%9C%A1%EA%B3%BC%EC%A0%95)의 **교과과정** 표 47행을 전사했습니다. 표의 게시·개정연도는 표시되어 있지 않습니다. 과목명은 공백을 지워 추정한 값이 아니라 원문과 대조한 이름입니다.
- [학교 공개 시간표](https://webinfo.dankook.ac.kr/tiac/univ/lssn/lpci/views/lssnPopup/tmtbl2.do)에서 **2026년 / 2학기 / 천안**을 선택했습니다. 공공인재대학 식품자원경제학과 전공 검색 24분반, 학문기초 검색 4분반, 융합 관련 과목 검색 9분반을 합쳤습니다. 융합 과목은 과목코드까지 대조했습니다.
- [2026학년도 학사종합안내](https://www.dankook.ac.kr/documents/d/kor/2026-1-_-260119-pdf?download=true)에서 트랙 표는 PDF 파일 72쪽·인쇄 60쪽, 교시표는 파일 138쪽·인쇄 4쪽에서 확인했습니다. 앞선 조사 기록의 트랙 표 ‘인쇄 61쪽’은 60쪽으로 정정합니다.
- 원문 전사와 구현 데이터를 행 단위로 비교했습니다. 시간표는 학사 과목코드와 분반의 조합으로 중복을 검사했고, 37행에 중복이 없었습니다. 학과 원문 37행과 추가 10행도 이름·코드·학점·학년·학기를 대조했습니다.
- PDF는 139쪽, 4,040,380바이트이며 SHA-256은 `2daf5d0e046b7182c243a30e49cafe08c90f347d8c9ce3b17eec12d5cef31207`입니다. 서버 수정 시각 `2026-08-27T11:19:56+09:00`을 공식 발행일로 해석하지 않았습니다.

## 잘못 해석하지 않도록 나눈 정보

- 교육과정의 배치 학년·학기와 이번 학기 실제 개설은 다릅니다. 이번 검색에 나오지 않았다고 폐지 과목으로 표시하지 않습니다.
- 학교 시간표의 **전공선택**과 트랙 계산의 **필수 과목**은 서로 다른 분류입니다. 기존 필수 적용 규칙을 바꾸지 않았습니다.
- 교수·강의실이 비어 있으면 **미표기**입니다. 아직 정해지지 않았거나 강의실이 없다고 단정하지 않습니다.
- 사전녹화 온라인 강의와 동기식 여부가 표시되지 않은 원격수업을 나눴습니다. 시간표에 적힌 시간만으로 원격수업의 충돌을 확정하지 않습니다.
- 야간 교시는 주간처럼 30분 간격이 아닙니다. 예를 들어 금요일 21~22교시는 **19:50~21:35**로 표시합니다. 토요일 수업도 검색에 포함했습니다.
- 공식 숫자 코드는 직접 과목 입력 검색에도 연결했습니다. 과목 상세에서 **학사 과목코드**와 **트랙 자료 코드**를 따로 보여 줍니다.

## 남은 확인 범위

시간표는 2026년 9월 8일 조회 시점의 정적 자료이며 실시간 연동이 아닙니다. 여석, 수강신청 가능 여부, 타 학과 학생의 수강 제한, 폐강·변경 사항은 학교 원문에서 다시 확인해야 합니다. 학과 표의 게시·개정연도와 개별 강좌의 수정일은 미표기입니다.

이번 자료 반영이 개인별 이수 인정이나 제공된 최종계획의 세부 계산 규칙을 공식 승인한 것은 아닙니다. 학생의 적용 학번, 인정학점, 트랙 이수와 졸업 여부는 학교·학과의 확인이 필요합니다.
