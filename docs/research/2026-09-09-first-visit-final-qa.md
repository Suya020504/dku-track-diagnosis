# 첫 방문 안내·서비스 흐름·명암비 검수

검수일: 2026-09-09. 대상은 현재 로컬의 미커밋 디자인 변경을 포함한 서비스다. 기존 파일, 수강 이력, 보관 기록을 보존했다. 사용자 요청 범위는 최종 검토, 첫 방문 안내 구현, 명암비 조정이다.

## Findings

- **F1 · P2 · 재방문 설문 위치 소실 — 수정.** 프로필이 있고 결과 확인 전인 학생의 홈 ‘이전 입력 이어보기’가 과목 입력으로만 이동했다. 저장 설문 문항과 트랙 선택 초안을 우선해 재개하도록 변경했다. 기존 답변·과목은 유지한다. 새 회귀 테스트에서 수정 전 실패, 수정 후 통과. 브라우저에서도 설문 1문항 답변 → 홈 → 이어하기 → 2번 문항 → 새로고침 후 2번 문항 복원을 확인했다.
- **F2 · P2 · 관심 추천 버튼의 진입 의도 불일치 — 수정.** 가이드 ‘관심으로 트랙 추천받기’가 이전 시작 방법을 유지했다. 관심 설문 의도를 직접 전달하도록 수정했다. 회귀 테스트 및 브라우저에서 트랙 직접 선택 경로 사용 후 가이드 버튼으로 관심 설문 진입을 확인했다.
- **F3 · P2 · 작은 글자와 입력 경계의 낮은 대비 — 수정.** 초록·파란 배지, 신청 순서 번호, 교육과정의 빈 배치 안내와 입력·선택 필드 경계를 조정했다. 튜토리얼은 별도 명암비를 확보했다. 장식 대시와 비활성 제어는 기준 적용 대상에서 제외했다.
- **F4 · P3 · 첫 사용자 안내 부재와 도움말 정보량 — 수정.** 기존 도움말은 요청 시 열리는 네 단계 설명과 입력 초기화가 함께 있었다. 첫 방문 홈에는 짧은 세 항목 안내만 표시하고 건너뛰기·닫기를 제공한다. 초기화는 기존 상세 도움말에 남겼다.

## Summary

현재 학생의 행동은 트랙 선택 또는 탐색 → 수강 이력 입력 → 남은 과목 확인 → 선택적 학기 계획이다. 병목은 중단한 위치와 버튼 목적의 불일치, 처음 보는 용어·작업 순서, 일부 연한 텍스트와 입력 경계였다. 해결은 라우팅·저장 상태·일반 UI로 처리했다. 서비스 내 AI 기능, 계정·동기화·신청 대행은 이 여정에 필요하지 않아 추가하지 않았다.

첫 방문 안내는 사용자의 답변대로 새 이용자에게 한 번만 표시한다. 프로필·초안·설문·과목·계획·보관 기록 중 하나라도 있으면 자동 표시하지 않는다. 가이드 같은 하위 주소를 열 때도 가리지 않는다. 안내 확인 여부는 수강 데이터와 다른 저장 키에 기록하며, 저장 실패 시에도 닫을 수 있다. 브라우저 데이터 삭제나 새 브라우저에서는 안내가 다시 나올 수 있다. 기존 이용자는 **도움말 → 처음 사용 안내 다시 보기**로 확인한다.

안내 제목은 ‘들은 과목으로 남은 수업을 찾아요’다. 본문은 시작 방법, 내 정보와 과목 입력, 남은 수업과 선택적 계획을 설명한다. 브라우저 저장과 학교 신청을 구별한다. 안내가 이해도나 과업 성공률을 높였다는 사용자 실험 결과는 없으며, 이번 검수는 구현·동작·가독성 확인이다.

### 명암비

일반 글자 4.5:1, 큰 글자 3:1을 기준으로 계산했다. [W3C 글자 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [모달 키보드 패턴](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)을 확인했다. 글자 색과 상위 요소 배경을 합성해 상대 휘도를 계산했으며 전체 WCAG 적합성 인증을 뜻하지 않는다.

| 수정 대상 | 수정 전 | 수정 후 |
|---|---:|---:|
| 파란 배지 | 4.23:1 | 5.34:1 |
| 초록 배지 | 3.18:1 | 4.85:1 |
| 신청 절차 번호 | 2.74:1 | 5.10:1 |
| 교육과정 배치 없음 | 3.28:1 | 4.62:1 |
| 입력·선택 필드 경계 | 1.52~2.33:1 | 3.37~3.84:1 |
| 꺼진 과목 토글 | 1.99:1 | 3.72:1 |

최종 브라우저 계산: 첫 안내의 텍스트13개는 네 화면 크기 모두 **최저5.32:1**. 수강 입력129개 최저4.59:1, 결과130개 최저4.52:1, 계획의 의미 있는 텍스트115개 최저4.59:1, 가이드45개 최저4.59:1. 모두 각 크기 기준 충족. 계획표의 aria-hidden 장식 대시는 최초 자동 계산에서 탐지됐으나 실제 의미 있는 텍스트가 아니므로 제외했다. 별도 기준의 입력 경계는 위 색상쌍으로 검사했다.
