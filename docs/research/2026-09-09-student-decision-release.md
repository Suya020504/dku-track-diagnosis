# 학생의 선택·수강신청 준비 보완과 배포

## Findings

- P2 해결: 결과의 한 가지 추천 조합이 모두 필수 과목인 것처럼 읽힐 수 있었다. 추천 조합으로 명명하고 대체 후보를 조회할 수 있게 했다. 한 과목만 교체한 상태로 선택한 모든 트랙의 모듈 학점 충족을 계산한다. 모듈 필수 표식·학번별 전공필수의 인정과는 구분하며 여러 대체를 동시에 적용하지 않는다.
- P2 해결: 현재 모듈 학점이 이미 충족된 상태에 추가 예정 과목이 있으면, 계획 미배치가 현재 충족 판정을 뒤집는 비교 오류를 독립 리뷰에서 재현했다. 현재 완료 이력의 충족을 먼저 판단하도록 수정하고 같은 사례 회귀를 통과했다.
- P2 해결: 대체 목록의 작은 학점 글자가 연한 초록 배경 위에서 4.21:1로 측정됐다. 해당 글자만 더 진하게 조정해 최종 실제 검사에서 미달 항목이 없었다.
- P3 해결: 입력하기 전 결과를 예상하기 어려워 가상 6과목 이력으로 한 트랙/두 트랙 결과와 예시 계획을 볼 수 있는 공유 주소를 추가했다. 기존 수강 이력·보관 기록은 변경하지 않는다.
- P3 해결: 학기 비교와 실제 학교 강좌 조회 연결이 부족해 비교 조건 입력, 공식 코드 복사·직접 복사 대안, 학교 시간표 링크를 추가했다.

## Summary

학생이 입력 전에 결과를 이해하고, 추천 조합의 의미와 다른 선택을 확인한 다음 목표 학기 안에 배치할 수 있는지 비교하며 수강신청 준비로 이어가는 개선이다. 계산은 기존 교육과정과 규칙을 재사용한다. 예시 결과와 비교는 개인 계획을 덮어쓰지 않는다. 계정·신청 대행·실시간 여석이나 미래 개설 확정 기능은 추가하지 않았다.

직접 공유할 예시 주소는 `/?view=example`이다. 가상 이수 완료 6과목은 f-1/f-2/h-1/i-1/j-1/l-1이며 실제 학생 자료가 아니다. 푸드마케팅만 선택하면 잔여4과목12학점, 농식품유통을 함께 선택하면 중복 제외8과목24학점이다. 예시 계획은 현재2026-2, 목표2028-2, 학기당3과목 가정이다.

## Verification

- 첫 예시 통합 테스트3개가 구현 전 실패했고 구현 후 통과했다. 직접 주소, 두 트랙 계산, 홈 복귀, 기존 저장값 동일성을 확인한다.
- 대체 후보 helper와 결과 UI는 복수트랙 교집합, 융합 모듈, 학점 부족 후보 제외, 수강중 미리보기, 원입력 보존을 검증한다.
- 학기 비교는 입력 완료 전 계산 없음, 조건 변경 시 오래된 결과 숨김, 현재충족 우선, 예시 마지막 학기 및 미배치 구분을 확인했다.
- 코드 복사는 공식 숫자코드만 사용하며 복사 실패·코드 미확인 시 대안을 제공한다. `446410` 실제 복사 후 클립보드와 일치를 확인했다.
- 전체 `npm.cmd test -- --reporter=dot`: **105파일 996개 통과**, 39.20초. 로그 `tmp/student-improvements-tests.log`. 마지막 복사 문구 개선은 별도3개 재통과.
- TypeScript/Vite 최종 빌드 통과, `git diff --check` 통과. 주 JS 약615kB의 기존 청크 경고 및 PDF Node legacy 권고는 유지한다. 로그 `tmp/student-improvements-build.log`.
- 새 예시·결과·비교·계획 4화면 × 390/430/820/1440px 총16개 조합에서 실제 너비를 확인하고 가로 넘침 없음을 확인했다. 대체 학점 대비 수정 후 결과4크기를 재검사해 미달0. 별도 검수 서버5175의 낡은 CSS 캐시는 재시작으로 해소했고 최종 스타일로 확인했다. 사용자 서버5173은 중단하지 않았다.
- 실제 예시 한/두 트랙 전환과 계획 보기, 결과 대체 후보 펼침, 목표학기 비교5개 결과, 조건변경 후 이전결과 숨김, 짧은 목표의 미배치 사유, 계획 생성과 코드복사, 학교 강좌 조회 링크를 확인했다.
- 공식 [천안 종합강의시간표](https://webinfo.dankook.ac.kr/tiac/univ/lssn/lpci/views/lssnPopup/tmtbl2.do)를 웹과 브라우저에서 확인했다. 연도·학기·전공 검색·과목명 필드가 있고 교과목번호는 결과표에 표시된다. 따라서 과목코드를 검색창에 넣으라는 초안 대신 과목명 검색 후 코드 대조 안내로 수정했다. 수강신청 제출은 하지 않았다.

## Remaining Risk

대체 후보는 모듈 학점 기준으로 한 과목씩 검증한 조회 목록이다. 실제 필수 인정이나 여러 과목을 동시에 바꾸는 계획을 자동 승인하지 않는다. 학기 비교는 2026년 개설 이력과 한 가지 추천 조합에 따른 배치 예시로, 미래 개설·최단 완료·전체 졸업을 보장하지 않는다. 실물기기·전체 스크린리더 감사·모든 실패 주입·실제 학생 사용성 실험은 미실행이다.

소개용 메일은 별도 로컬 산출물로 작성했고 저장소·배포에 포함하지 않는다. 메일 발송은 하지 않았다.
