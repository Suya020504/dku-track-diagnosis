# 다중 트랙 여정 개편 검수 · 2026-09-09

## Findings

- 설문 완료 직후의 옛 단일 선택 결과, 학적 미정 학생에게 노출되던 전공 전체 계획, 계획에 담을 때 무조건 다음 학기를 지정하던 경로를 수정했다.
- 계획 입력 변경 뒤 초안과 계산 결과를 분리하고, 트랙·과목 변경 시 조건은 보존하되 이전 결과는 무효화한다. 보관 기록은 현재 입력 초기화와 분리한다.
- UI 검수에서 태블릿 결과 요약의 세로 줄바꿈, 모바일 제목의 한 글자 줄바꿈, 홈 외곽의 구형 배경과 계획 상단 여백을 수정했다.
- 최종 독립 검토에서 과거 계획을 현재 교육과정으로 재검증하던 문제와 새 흐름에서 초기화 접근이 사라진 문제를 수정했다. 현재 카탈로그에서 과목이 삭제되면 수동 배치 키 때문에 전체 저장 상태가 탈락하던 경계도 재현 후 수정했다. 보관 계획은 당시 입력·모듈 범위·배치를 구조 검증하고, 현재 계획만 최신 데이터로 검증한다.

## Summary

사용자 승인 범위는 여러 트랙 선택, 신청 안내 연결만 제공, 검증 뒤 GitHub·운영 갱신이다. 설명은 선택이며, 내 정보 이후 `알고 있는 트랙 / 관심 설문 / 이수 이력` 세 경로가 다중 트랙 결과에서 만난다. 남은 과목은 트랙 모듈 조건의 합집합으로 계산한다. 전체 전공·학번별 필수·공식 이수 인정과 섞지 않는다.

suya-service-flow로 분기와 저장 계약, suya-service-design으로 화면별 위계·시안 대조, suya-service-qa로 상태·반응형·릴리스 검증을 진행했다. ImageGen으로 진입/결과/계획 시안과 분리된 노트 자산을 제작했다. 연구 기록은 GitHub 문서이며 Vercel 업로드에서 제외한다. 원문 PDF/HWP는 공개하지 않는다.

### 실제 브라우저 범위

CUA의 기존 인앱 브라우저로 조작했다. 로컬 `localhost:5173`를 실제 사용자 `127.0.0.1` 및 운영과 다른 출처로 사용하고 합성 QA 입력만 변경했다. 테스트를 위해 사용자 원본 기록을 초기화하지 않았다.

- 직접 선택: 2개 트랙 체크 → 새로고침 → 확인 → 공통 잔여 14과목. 한 과목을 두 트랙에서 중복 합산하지 않는다.
- 계획: 과목 담기 → 공동 계획 생성 → 학기 직접 이동 → 보관 → 새로고침 → 동일 학기 복원. 이전 합성 기록 1개와 새 계획 1개가 함께 유지됐다.
- 관심: 타 학과·부전공 → 10문항 → 2개 추천 선택 → 새로고침 → 확인. 부전공 정보는 트랙 선택으로 바뀌지 않는다.
- 이력: 식품유통경제학 완료, 마케팅조사분석 수강 중 입력 → 5개 트랙 비교 → 2개 확정. 완료 기준 13과목·39학점, 수강 중 미리보기 12과목·36학점으로 변경되며 원본 완료 상태는 변경하지 않는다.
- 5개 모두 선택: 동일 합성 이력으로 24과목·66학점. 결과 표와 5개 모듈 현황이 표시되고 가로 페이지 넘침은 없다. 이 수치는 QA 입력 예시이지 졸업 기준이 아니다.
- 344×882 폴드 외부 너비의 5트랙 결과, 390×844 계획, 430px 결과, 820×1180 결과, 1536×1024 대표 3화면, 1920×1080 다중 결과를 직접 확인했다. 실제 기기 검증이 아닌 Chromium 뷰포트 검증이다.
- 5트랙에서 2026-2→2028-2, 학기당 최대4개로 계획하면 7개 미배치와 수강량 조정 안내가 표시됐다. 현재 수강 중 1개는 현재 학기에 고정하고 자동 배치16개는 이후4학기로 분배했다.
- 공통 도움말의 초기화 안내 → 보관 유지 문구 → 취소 → 닫기를 실제로 확인했다. 브라우저의 삭제 확인 버튼은 실행하지 않았다.
- 계획 화면은 360×800, 768×1024, 1024×768에서도 페이지 넘침0·main1·h1 1·오류 오버레이 없음으로 확인했다. 가로형 태블릿 캡처도 직접 확인했다.
- 진입·결과·계획 생성 시안과 네이티브 캡처를 각각 열어 비교했다. [시안 대조 기록](../../design-proposals/2026-09-09-journey/DESIGN-IMPLEMENTATION.md)에 의도적인 차이를 명시했다.

## Remaining risk

- 제공 자료의 모듈 조건을 계산하는 보조 도구다. 전체 졸업·신청·학번별 인정과 혼동하지 않도록 범위를 나눈다.
- 미래 개설을 보장하지 않는다. 자동 계획은 현재 선택한 최소 과목 조합을 배치하며, 같은 비용의 다른 과목 조합까지 재탐색해 최적 시간표를 보장하지 않는다.
- PDF 자동 입력은 기존 beta 한계를 유지한다. 실물 모바일·전체 대비·실사용 성능 측정은 이번 완료 범위 밖이다.
- 학생 입력은 로그인 없이 해당 브라우저에 남는다. 기기 간 동기화나 공식 신청 상태는 제공하지 않는다.
