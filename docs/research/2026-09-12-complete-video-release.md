# 최신 사용 방법 영상 · 기능별 목차 검수

2026-09-12. 최신 서비스의 실제 조작 전후를 촬영하고 기존 안내에서 빠진 기능을 설명하는 작업이다. 이전 영상과 사용자 기록을 보존한다.

## 변경

- 5분 32초, 20개 기능 목차, 50개 편집 장면(원본 캡처 48개). 소속부터 관심 설문 완료·과목 입력·이력 비교·진단 결과·계획 수정·보관·자료·도움말까지 이어진다.
- 영상 아래 접힌 목차에서 원하는 시각으로 이동한다. 재생/일시정지 상태를 유지하며 자동 재생하지 않는다. 미디어 로드 전 이동 예약과 재시도, 짧은 파일의 범위 보정도 처리한다.
- ‘이 기능 직접 열기’는 현재 선택한 기능 하나만 연다. 실제 개인 기록 화면을 이용하고 예시 데이터를 복사하지 않는다. 모듈·교육과정·시간표는 각각 해당 탭, 도움말은 기존 모달로 이어진다.
- 재방문 홈의 ‘다른 방법으로 시작하기’를 기본 펼침으로 바꿨다. 접고 다시 여는 동작은 유지한다.
- 새 파일은 날짜가 붙은 MP4/JPG/VTT로 저장하고 이전 86초 영상은 유지했다. 제작 원본은 design-proposals/2026-09-12-service-guide에 보존하며 배포 업로드에서 제외한다.

## 검증

- 전체107파일1031개 자동 테스트 통과. 후속 길이 표시를 ‘분·초’로 다듬고 최종 목차를 직접 참조하도록 정리한 후 관련2파일26개 테스트 재통과.
- 목차 시간은0초부터332초까지 중복·공백 없이 연결된다. 실브라우저에서20개 목차를 전부 눌러 해당 시작 시간과 활성 표시, 일시정지 유지가 맞는지 확인했다.
- 실제 영상은332초/readyState4로 로드되고208초에서 재생해214.49→225.15초로 진행, 일시정지를 확인했다. 제작 파일의 H.264/1080p/25fps/8300프레임/무음/faststart와 VTT를 점검한다.
- 실브라우저에서 일시정지 조작부가 자막을 가리는 것을 발견해 자막 아래156px을 확보했다. 화면 캡처 영역과 제목·자막 영역을 분리한다.
- 도움말 직접 열기·닫기 후 호출 버튼 초점 복원, 모듈/교육과정/시간표의 실제 탭 연결을 확인했다. 신규 입력 유도·개인 기록 보존은 앱 회귀 테스트에서도 검사했다.
- 320×740, 390×844, 906×912, 1280×720에서 영상·목차의 가로 넘침이 없었다. 320px에서 목차 버튼 최소 높이44px, 모바일1열/태블릿2열 배치를 확인했다. 모바일에서 시간표 장면 선택 후 실제 시간표로 이동했다.
- 최종 영상은7,978,256바이트, SHA-256 `fd64fb7f77fc3d4646f886085c5ddd77aad43828279405c2b1f91d35a98814a5`다. 모든50개 장면에서 자막이 하단156px을 침범하지 않음을 검사했고, 최종 실브라우저 일시정지 화면에서 자막 두 줄과 조작부가 분리됨을 확인했다. 마지막 빌드의 타입검사·번들 생성도 통과했다.
- 독립 읽기 전용 코드 리뷰에서 근거로 확정할 P1/P2 회귀가 발견되지 않았다.

## 범위 밖

연속 화면 녹화나 음성 해설이 아니라 실제 화면 캡처를 편집한 자막 영상이다. PDF 읽기 완료, 초기화 실행, 인쇄 대화상자, 외부 신청 제출은 시연하지 않았다. 과거 호환 주소의 옛 전공 전체 플래너까지 모든 제어를 촬영한 것은 아니며 현재 주사용 흐름을 다룬다. 실제 단말·전체 스크린리더 검증이나 학생 사용성 실험은 별도다. 개인별 이수 인정·미래 개설은 학교의 공식 확인이 필요하다.
