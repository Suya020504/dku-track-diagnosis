# 자료 화면 검증 기록 보관

기록일: 2026-09-09

이 문서는 학생용 자료 화면에서 분리한 검증 메모를 보관한다. GitHub 저장소의 유지보수·검수용 문서이며, 서비스 화면에 불러오거나 공개 화면의 도움말로 연결하지 않는다. UI에서 설명을 줄였다고 해서 데이터의 근거 상태나 계산 규칙이 달라진 것은 아니다.

## 이번 변경 범위

`OfficialResourcesView.tsx`에서 검증 기록 펼침 영역과 바로가기 설명의 확인일·쪽수·분반 집계 메타데이터를 옮겼다. 학사종합안내 링크는 특정 PDF의 `#page=72` 위치 대신 천안 학사종합안내 페이지로 연결한다. 영상의 제목·재생시간·링크와 학과 문의 경로는 유지한다.

`ModuleReferenceView.tsx`에서는 M·N·O 모듈의 `sourceNote`와 「자료 범위와 주의 사항」을 화면에 표시하지 않는다. A~O 15개 모듈, 과목 49개, 과목명·학점·학사 과목코드·트랙 자료 코드, 검색, 모듈 펼침은 유지한다. A 학문기초 4과목을 제외한 직접 진단 전공 입력 목록이 45과목이라는 구분도 유지한다.

`OFFICIAL_2026_SOURCE`, `COURSE_OFFERING_SNAPSHOT_META`, 과목·모듈 원본 데이터, 진단 엔진, 저장된 사용자 기록은 이번 화면 정리에서 변경하지 않았다.

### M. 바이오헬스혁신융합

> PDF 과목표에는 세부 과목 코드가 N-1~N-5로 표기되어 있어 모듈명 기준으로 M에 매핑했습니다.

### N. 식품영양학
